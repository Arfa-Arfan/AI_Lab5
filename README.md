# AI_Lab5 # 🧠 Interactive Python Tasks

This project includes five mini interactive Python programs showing key coding concepts like logic, decision-making, and user input.

1️⃣ *Intent Classifier* – Detects user intent using keyword rules (greetings, thanks, study, etc.).  
2️⃣ *Scholarship Decision* – Decides scholarship eligibility from CGPA, income, and achievements.  
3️⃣ *Activity Recommender* – Suggests activities based on mood and time of day.  
4️⃣ *Traffic Light FSM* – Simulates a traffic light using a finite state machine system.  
5️⃣ *Input Helpers* – Ensures valid and safe user inputs through strong validation.
